# Changelog

## 0.1.0 — 2026-11-25
**First version** — Lex Studio, the pop-up dictionary of the Studio family (Pre-Alpha).
- Ten languages in any pair: Latin, Ancient Greek, English, German, French, Spanish, Russian, Italian, Swedish, Japanese.
- Small window that a key combination brings up at the mouse pointer with the copied word looked up; Escape hides it;
  stays in the tray / menu bar.
- Translations, meanings and forms from Wiktionary (German and English); inflected forms lead to the basic form,
  Japanese kana to the kanji words; through English when there is no direct translation.
- Loose search without accents / breathings, suggestions while typing, typing Greek / Russian / Japanese with Latin letters.
- Word list with CSV export; answers kept for offline use.
- MCP server (`--mcp`): lookup, suggest, languages.
- All Studio themes and layouts (incl. Proton), German / English.
